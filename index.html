Common Questions

Frequently Asked Questions

Everything you need to know about Zero-Code Sync and Bubble Workload Units.

Does this really consume 0 Bubble Workload Units?
Yes, 100%. Traditional Bubble searches run on Bubble's database servers via :filtered or SQL scans, charging you Workload Units for each keystroke. Zero-Code Sync queries your dedicated Meilisearch cluster directly from the user's browser, completely bypassing Bubble's servers and eliminating search WUs.
How does data sync from Bubble to Meilisearch?
You can sync your data in two ways: either run a 1-click initial bulk sync from our dashboard, or configure native Bubble Database Triggers (Backend Workflows) that automatically push new or updated records to Zero-Code Sync in real time.
Can I use my own self-hosted Meilisearch instance?
Absolutely. You can use our fully managed cloud cluster, your own Meilisearch Cloud account, or any self-hosted Meilisearch instance running on AWS, DigitalOcean, or Hetzner. Just plug in your Meilisearch Host URL and API key.
Does it work on the Bubble Free or Starter plan?
Yes! The client plugin works seamlessly across all Bubble plans, including Free and Starter tiers. It simply binds to any standard input element and outputs an array of Bubble unique IDs for your Repeating Group.
